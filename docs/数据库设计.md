# 数据库设计

> 完整表结构与字段定义见 `docs/计划初稿.md` 第 6 章。本文记录统一规范。

## 规范

- 库名 `pet_platform`，MySQL 8.0，统一 `utf8mb4`。
- 主键 `BIGINT` 自增；金额 `DECIMAL(10,2)` + Python `Decimal`。
- 时间 `DATETIME`，应用层按 UTC 存取，业务时区 `Asia/Shanghai`，API 使用带时区 ISO 8601。
- 通用字段 `created_at` / `updated_at`（`TimestampMixin` 提供）；必要表加 `deleted` 软删除。
- 状态字段使用字符串枚举。
- 核心关系建外键、唯一约束、索引；跨业务历史记录不级联物理删除。
- 所有表结构只经 Alembic 迁移创建与修改，禁止启动时 `create_all()`。
