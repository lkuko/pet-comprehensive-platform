# 开发与部署说明

> 完整约定见 `docs/计划初稿.md` 第 15 章。

## 本地开发

```bash
# 1. 基础设施
cp .env.example .env
docker compose up -d mysql redis

# 2. 后端
cd server
python -m venv .venv && .venv\Scripts\activate   # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp ../.env.example .env
alembic upgrade head
uvicorn app.main:app --reload

# 3. 前端
cd ../admin-web && npm install && npm run dev
cd ../user-web  && npm install && npm run dev
```

## 环境变量

`.env.example` 为唯一配置名来源，`server/.env` 供本地后端读取，`docker-compose` 从根 `.env` 读取。三者字段名保持一致。

## 生产部署最低要求（Day 10 落地）

- 生产 `.env`，关闭 Debug，换强随机 JWT Secret 与数据库密码。
- 只暴露 Nginx；MySQL/Redis 不直连公网；上传目录持久化；Nginx 配置 WebSocket Upgrade。
- 本项目 V1 仅提供模拟支付，不得伪装为真实支付。

## 可重复启动

- 空环境仅凭 Alembic migration 初始化；应用启动不隐式建表。
- 重复执行 seed 不产生重复数据（seed 脚本在 Day 2+ 落地）。
